# Changelog

# News

Initial registered release of QuantumExpanders.jl.

## [0.1.0] - 2026-9-21

- Add `QuantumTannerCode` for constructing explicit quantum Tanner codes from left-right Cayley complexes.
- Add `QuantumTannerViaLeftRightActions` for constructing lifted quantum Tanner codes through commuting left and right group actions.
- Add generation of symmetric generating sets for finitely presented groups.
- Add puncturing of classical binary linear codes for quantum Tanner code constructions.
- Add constructions of Morgenstern Ramanujan graphs for even prime-power parameters.
- Add Lubotzky–Phillips–Sarnak Ramanujan graph constructions.
- Add Ramanujan graph constructions based on Frobenius groups.
- Add deterministic and randomized construction of bipartite and quadripartite quantum Tanner codes.
- Add documentation and reproducibility tests for the quantum Tanner code instances reported in *Quantum Tanner Codes at Moderate Blocklength*.
- Remove precompilation errors caused by method overwriting.
