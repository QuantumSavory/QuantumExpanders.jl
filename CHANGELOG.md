# Changelog

# News

Initial registered release of QuantumExpanders.jl.

## [0.1.0] - dev

- Add `QuantumTannerCode` for constructing explicit quantum Tanner codes from left-right Cayley complexes (#25).
- Add `QuantumTannerViaLeftRightActions` for constructing lifted quantum Tanner codes through commuting left and right group actions (#93).
- Add generation of symmetric generating sets for finitely presented groups (#38).
- Add puncturing of classical binary linear codes for quantum Tanner code constructions (#55).
- Add constructions of Morgenstern Ramanujan graphs for even prime-power parameters (#16).
- Add Lubotzky–Phillips–Sarnak Ramanujan graph constructions (#6).
- Add Ramanujan graph constructions based on Frobenius groups (#12).
- Add deterministic and randomized construction of bipartite and quadripartite quantum Tanner codes (#34).
- Add documentation and reproducibility tests for the quantum Tanner code instances reported in *Quantum Tanner Codes at Moderate Blocklength* (#93).
- Remove precompilation errors caused by method overwriting (#8).
